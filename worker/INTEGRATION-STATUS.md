# Optional media-provider experiment

This folder and `media/cloudinary-local.mjs` contain an earlier optional moderation experiment. It is not enabled in the current Wamda guest app. The current app stores compressed demo images in Firestore without automatic content screening.

The optional adapter requires separate credentials supplied through a private external file and isolated emulators. No credentials are included. Synthetic and mock adapter checks are not evidence of real harmful-image detection. Do not enable, upload content to, or incur charges with an external provider without separate approval.
